# Thai Vocab - คลังคำศัพท์ภาษาไทยสำหรับ Tablet & Desktop 🇹🇭

เว็บแอปพลิเคชันเรียนรู้คำศัพท์ภาษาไทย แบ่งตามหมวดหมู่การใช้งาน พร้อมระบบแสดงคำอ่านออกเสียงและเสียงอ่านภาษาไทย (Text-to-Speech) ออกแบบมาให้ใช้งานได้ดีเยี่ยมบน **Tablet (iPad / Android Tablet)** และคอมพิวเตอร์ทั่วไป

---

## 🌟 ฟีเจอร์เด่น
1. **คลังคำศัพท์ 550 คำ:** 10 หมวดหมู่หลัก (อาหาร, สัตว์/ธรรมชาติ, ร่างกาย/สุขภาพ, ชีวิตประจำวัน, การเดินทาง, อารมณ์, อาชีพ, การศึกษา/วิทยาการ, พระพุทธศาสนาและพระสงฆ์, คำน่ารู้และสำนวนไทย)
2. **ระบบเสียง 2 ระบบ (Dual Voice Engine):**
   - 🌐 **Google Thai (แนะนำ):** เสียงอ่านสำเนียงคนไทยแท้ 100% ชัดเจน เป็นธรรมชาติ ไม่เพี้ยน
   - 📱 **ระบบเสียงในเครื่อง (Device TTS):** คัดเลือกเสียงที่ดีที่สุดในระบบ และทำงานแบบออฟไลน์ได้
3. **ปรับความเร็วเสียง:** ฟังปกติ 1.0x, ปานกลาง 0.8x, หรือช้าชัดถ้อยชัดคำ 0.6x
4. **โหมดแฟลชการ์ด (Flashcards):** พลิกการ์ด 3D เพื่อทายคำอ่านและความหมาย
5. **โหมดแบบทดสอบ (Quiz Game):** มินิเกมทดสอบความจำคำศัพท์ 10 ข้อ มีเสียงเอฟเฟกต์และสรุปคะแนน
6. **บันทึกคำโปรด (Favorites):** บันทึกคำศัพท์ที่อยากทบทวนซ้ำ
7. **เพิ่มคำศัพท์เองได้:** มีเมนู "เพิ่มคำศัพท์" ให้คุณครูหรือผู้ใช้เพิ่มคำของตัวเองลงในแอปได้ทันที
8. **เหมาะกับ Tablet:** ปุ่มกดขนาดใหญ่ สัมผัสง่าย รองรับการกดแบบสัมผัส และมีปุ่มเปิดเต็มจอ (Fullscreen)

---

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดทดสอบบนคอมพิวเตอร์ทันที
เพียงแค่ **ดับเบิลคลิกที่ไฟล์ `index.html`** เพื่อเปิดในเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari) ได้ทันที

---

### 2. วิธีให้ผู้ใช้ Tablet ใช้งานผ่าน Wi-Fi ในบ้าน/ห้องเรียนเดียวกัน
หากคอมพิวเตอร์และ Tablet เชื่อมต่อ Wi-Fi เดียวกัน:
1. เปิด Terminal / PowerShell ที่โฟลเดอร์นี้ แล้วรันคำสั่ง:
   ```bash
   python -m http.server 8080
   ```
2. ดู IP Address ของคอมพิวเตอร์ (พิมพ์ `ipconfig` ใน cmd จะเห็น เช่น `192.168.1.50`)
3. บน Tablet ให้เปิด Safari หรือ Chrome แล้วพิมพ์:
   ```text
   http://192.168.1.50:8080
   ```
4. สามารถนำลิงก์นี้ไปแปลงเป็น QR Code ให้ Tablet ยกกล้องสแกนได้เลย

---

### 3. วิธีนำขึ้น GitHub เพื่อให้คนอื่นใช้งานได้ฟรีทั่วโลก (แนะนำที่สุด ⭐)
ขนาดไฟล์ทั้งหมดเพียงไม่กี่กิโลไบต์ (KB) สามารถนำขึ้น GitHub ได้ฟรีและรวดเร็ว:

1. **สร้าง Repository ใหม่บน GitHub:**
   - ตั้งชื่อ เช่น `thai-vocab`
2. **อัปโหลดไฟล์ในโฟลเดอร์นี้:**
   - นำไฟล์ `index.html`, `app.js`, `words.js`, `manifest.json` ขึ้น GitHub
3. **เปิด GitHub Pages (ฟรี 100%):**
   - ไปที่แท็บ **Settings** ของ Repository บน GitHub
   - เมนูด้านซ้ายเลือก **Pages**
   - ตรงช่อง **Branch** ให้เลือก `main` แล้วกด **Save**
4. **ได้เว็บไซต์พร้อมใช้งานทันที:**
   - คุณจะได้ URL เว็บไซต์ เช่น: `https://your-username.github.io/thai-vocab/`
   - นำลิงก์นี้ไปวางที่เว็บสร้าง QR Code (เช่น [qr-code-generator.com](https://www.qr-code-generator.com/))
   - ปริ้นท์หรือส่ง QR Code ให้ผู้ใช้ Tablet **ยกกล้องสแกนเปิดใช้งานได้ทันทีทั่วโลก!**

---

### 4. วิธีทำให้เป็นแอปบนหน้าจอ Tablet ("Add to Home Screen")
เมื่อเปิดเว็บขึ้นมาบน Tablet แล้ว:
* **บน iPad (Safari):** กดปุ่มแชร์ (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น) $\rightarrow$ เลือก **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
* **บน Android Tablet (Chrome):** กดจุด 3 จุดมุมขวาบน $\rightarrow$ เลือก **"ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"**
* แอปจะปรากฏเป็นไอคอนบน Tablet เปิดแล้วทำงานแบบเต็มจอเหมือนแอปแท้ทันที!
